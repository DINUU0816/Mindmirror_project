# Mind Mirror

Mind Mirror is an AI-powered mental wellness and emotion analysis platform that helps users understand emotional patterns using machine learning and sentiment analysis.

## Features
- Emotion Detection
- Sentiment Analysis
- Wellness Recommendations
- Analytics Dashboard
- Responsive User Interface
- REST API Integration

## Tech Stack

### Frontend
- React.js
- Tailwind CSS

### Backend
- Django
- Django REST Framework

### Database
- SQLite / MySQL

### AI / ML
- NLP Models
- Emotion Detection
- Sentiment Analysis

## Objective
The project aims to provide intelligent emotional insights and mental wellness support using AI-driven analysis and visualization.
